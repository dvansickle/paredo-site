Changelog

What’s changing in Paredo for QuickBooks Online. Updates appear here newest first.

Last updated November 2, 2026. Chrome Web Store review and automatic updates can take time; your installed version may differ. These notes describe extension changes, not changes to your accounting records.

0.24.1 — A simpler trial welcome

November 1, 2026 · Submitted for Chrome Web Store review

  • Removed a duplicate trial-status message from the welcome menu.
  • Moved subscription and recovery actions under More options before a trial has started, keeping the trial action easier to find.
  • Kept Check activation and any pending or error instructions visible after opening signup.

Saved display preferences and trial terms are unchanged. Publication of this update has not yet been confirmed.

0.24.0 — Easier to get started

November 1, 2026 · Development update

  • Added a visible green Paredo · Start free trial entry when a trial has not started.
  • Added a one-time welcome panel on supported screens. Dismissing it leaves the trial entry available without reopening the panel on every refresh.
  • Put trial and activation controls first while access is inactive, and added clearer email-confirmation guidance and Check activation.

Starting a trial remains your choice. Without active access, QuickBooks stays available in its native layout. These changes are included in the 0.24.1 submission above.

0.23.1 — The Paredo baseline

The Chrome Web Store version used for the initial public website screenshots.

  • Introduced the Paredo name and P icon, previously developed as Simplify QBO.
  • Offers display adjustments on selected QuickBooks Online screens, including Home, Bank Transactions, Invoices and selected reports.
  • Includes per-screen visibility controls, locally saved display preferences, and access to the native layout.

This page begins with the public Paredo baseline; earlier experimental versions are not listed individually. Coverage varies by QuickBooks account and interface.

Something looks wrong?

Turn Paredo off for the affected screen to return to QuickBooks’ native layout. Contact support with the screen name and extension version, and redact private information from any screenshots.
