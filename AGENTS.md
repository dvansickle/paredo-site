# Working on Paredo website

Work directly on `main`. The owner only works in main: do not create branches or pull requests. Commit and push when requested.

This repository contains the public static website only. Keep site files at the repository root; GitHub Pages deploys directly from `main` / `(root)` using Deploy from a branch. Preserve `CNAME` and `.nojekyll`. No build step or dependency installation is required.

Preserve unrelated changes, check `git diff --check` before committing, and verify local asset links after website changes. Do not add private QuickBooks screenshots, records, credentials, analytics, or billing integrations.
